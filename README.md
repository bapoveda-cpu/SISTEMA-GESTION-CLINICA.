# Sistema de Gestión Clínica - Proyecto Académico
Este proyecto es una aplicación Android diseñada para optimizar la administración de pacientes, médicos y servicios de salud en centros de atención primaria.

##  Características
* **Gestión de Pacientes:** Registro y consulta de historias clínicas.
* **Control de Médicos:** Gestión de perfiles y asistencia.
* **Agendamiento:** Control de citas y turnos médicos.
* **Recetas e Informes:** Generación digital de documentos médicos.

## Tecnologías utilizadas
* **Lenguaje:** Kotlin
* **Interfaz:** Jetpack Compose
* **Base de Datos:** Room (SQLite)
* **Arquitectura:** MVVM (Model-View-ViewModel)
